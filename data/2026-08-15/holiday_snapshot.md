## 🔧 流程備註（本次發現的兩處腳本陷阱）

1. **`fetch_us_asia_markets.py` 不可用 `>` 重導向**：該腳本預設 `--format both`，
   進度訊息與 JSON 同走 stdout，`> us_asia_markets.json` 會產出**無效 JSON**
   （本次首跑即中招，`json.load` 失敗）。已改用 `--output-dir data/2026-08-15` 重跑並通過驗證。
   `us_leader_alert.py` 因內建 markdown 容錯剝離而未報錯，**故此類污染不會自曝**。
2. **`gh api ... --jq '.content' | base64 -d` 需先 `tr -d '\n'`**：GitHub API 回傳的 base64
   含換行，直接 decode 會失敗。本次首次抓取 market_intelligence 即因此失敗並被誤判為
   「週六無產出」，實際檔案存在（74,765 bytes）。已補上 `tr -d '\n'` 後成功取得。
